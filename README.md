# Arduino Tabanlı Akıllı Güneş Takip Sistemi ☀️

Bu proje, güneş enerjisi sistemlerinde verimliliği artırmak amacıyla geliştirilmiş **Arduino tabanlı akıllı güneş takip sistemi**dir.  
Sistem, güneşin gün içerisindeki konumunu **LDR (Light Dependent Resistor) sensörleri** ile algılayarak güneş panelini otomatik olarak en uygun açıya yönlendirir.

## 📌 Proje Amacı
Sabit konumlu güneş panellerinde oluşan verim kaybını azaltmak ve panel yüzeyine gelen güneş ışığını maksimum seviyeye çıkarmak.

## ⚙️ Sistem Çalışma Prensibi
- Dört adet LDR sensörü farklı yönlerden gelen ışık yoğunluğunu ölçer.
- Arduino Nano, sensörlerden gelen analog verileri karşılaştırır.
- Işık yoğunluğu farklarına göre iki adet servo motor kontrol edilir.
- Panel, yatay ve dikey eksende güneşe doğru otomatik olarak yönlendirilir.
- Sistem döngüsel olarak çalışarak sürekli güneş takibi sağlar.

## 🧠 Kullanılan Teknolojiler

- Servo Motorlar
- C/C++ (Arduino IDE)
